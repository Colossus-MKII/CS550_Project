# Reproducibility resources

`downloaded-resources.json` is generated by `tools/download_project_resources.ps1`. It records the source URL, file size, and SHA-256 hash for each locally downloaded pilot video and pretrained checkpoint.

The large files themselves are intentionally ignored by Git:

- `data/pilot/videos/`
- `data/raw/`
- `models/checkpoints/`

Official project sources:

- YouTube-VIS 2021: <https://youtube-vos.org/dataset/vis/>
- Ultralytics YOLO11: <https://docs.ultralytics.com/models/yolo11/>
- Meta SAM 2.1: <https://github.com/facebookresearch/sam2>
- Segment and Track Anything: <https://github.com/z-x-yang/Segment-and-Track-Anything>
- AOT/DeAOT: <https://github.com/yoxu515/aot-benchmark>
- OpenCV background subtraction: <https://docs.opencv.org/4.x/d1/dc5/tutorial_background_subtraction.html>

Review the upstream licenses and dataset terms before redistributing any checkpoint, video, annotation, or derived dataset.
